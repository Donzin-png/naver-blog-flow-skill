# Google Flow 프롬프트 템플릿

아래 문장을 그대로 쓰거나 주제만 바꿔서 사용한다. 공통 규칙:

- 탑뷰 일러스트에는 **텍스트와 글자를 넣지 않는다.** Flow가 한글을 잘못 그리는 경우가 많다. 라벨은 원고의 캡션으로 붙인다.
- 실사진은 4:3, x1, 1K 원본 크기로 생성한다. 비교 단면도 4:3, 시공 흐름도 16:9가 보기 좋았다.
- 주제가 바뀌면 `문선`, `MDF`, `도배` 같은 자재 이름만 치환한다.

## 1. 실사진 — 기존 문선 철거

```
현대 아파트 복도 문틀에서 목수가 기존의 두꺼운 문선을 철거하는 사실적인 사진. 커터칼로 실리콘을 끊고 지렛대로 문선을 조심스럽게 떼어내는 손 클로즈업. 벽지는 훼손되지 않은 상태. 자연스러운 실내 조명, 사실적인 질감, 4:3 비율.
```

## 2. 실사진 — 재단과 부착

```
목수가 각도 절단기로 재단한 얇은 MDF 문선을 문틀에 정확히 붙이는 사실적인 사진. 접착제와 타카로 고정하고 퍼티로 못자리를 메우는 과정. 깔끔한 현장, 사실적인 목재 질감, 자연스러운 조명, 4:3 비율.
```

## 3. 실사진 — 완성

```
9mm 슬림 문선으로 마감한 아파트 방 문 클로즈업. 문선이 벽지와 같은 톤이라 벽이 매끄럽게 이어져 보인다. 밝고 정돈된 모던 인테리어, 사실적인 사진, 4:3 비율.
```

## 4. 2D 탑뷰 — 기존 vs 슬림 비교 단면

```
단순한 2D 평면 인포그래픽 일러스트, 위에서 내려다본 탑뷰 단면도. 화면을 세로로 반으로 나눔. 왼쪽은 기존 방식: 문틀 주변에 두꺼운 문선이 계단처럼 여러 단으로 돌출되어 벽면보다 튀어나와 있음. 오른쪽은 9mm 방식: 아주 얇은 문선이 벽지 면과 거의 같은 선에 맞아떨어져 벽과 매끄럽게 이어짐. 흰색 문짝, 연한 회색 벽, 짙은 회색 문선. 균일한 굵기의 깔끔한 선형 스타일, 흰 배경, 텍스트와 숫자와 글자 없음, 4:3 비율.
```

## 5. 2D 탑뷰 — 시공 4단계 흐름

```
단순한 2D 평면 인포그래픽 일러스트, 위에서 내려다본 탑뷰. 문틀 상단 부분을 위에서 본 단면도가 가로로 네 단계 나란히 놓이고 화살표로 순서대로 연결됨. 첫 번째는 두꺼운 기존 문선이 붙어 있는 상태, 두 번째는 문선을 떼어내고 문틀만 남은 상태, 세 번째는 얇은 새 문선을 문틀에 정확히 붙이는 상태, 네 번째는 벽지와 같은 톤으로 마감되어 벽과 일직선이 된 상태. 미니멀한 선형 아이콘 스타일, 연한 회색과 흰색 톤, 흰 배경, 텍스트와 글자 없음, 16:9 가로 비율.
```

## 6. 다른 주제로 치환할 때

| 자리 | 예시 |
| --- | --- |
| 주제 | 9mm 문선 → 슬림 걸레받이, 무문선 도어, 마이크로 시멘트 |
| 자재 | MDF → 합판, 알루미늄, 우레탄 |
| 마감 | 도배 → 도장, 필름 |

치환 뒤에도 "단면 비교"와 "순서 흐름" 두 장은 유지하면 독자가 이해하기 쉽다.
